# Math Quiz

A simple **Math Quiz** built using Python that tests basic arithmetic skills
and keeps track of the user's score.

## Features

- Addition questions
- Subtraction questions
- Multiplication questions
- Division questions
- Instant answer checking
- Displays the correct answer for wrong answers
- Score tracking
- Final score display

## Technologies Used

- Python
- Lists
- Tuples
- `for` loop
- `if-else` statements
- User input
- Arithmetic operators

## Concepts Learned

- Variables
- Lists and tuples
- Loops
- Conditional statements
- User input
- Type conversion
- Arithmetic operations
- Score calculation
- Basic quiz logic
